PROMPT
Set up the Sarvam MCP server on this machine. Repository: https://github.com/sarvamai/sarvam-mcp Please do the following, in order: 1. CLONE git clone https://github.com/sarvamai/sarvam-mcp.git ~/sarvam-mcp cd ~/sarvam-mcp (If the directory already exists, just `git pull` it.) 2. INSTALL Prefer `uv` if available, else fall back to venv + pip: if command -v uv >/dev/null; then uv venv -p 3.11 .venv uv pip install -e . else python3 -m venv .venv .venv/bin/pip install -e . fi Confirm the binary works by running: ~/sarvam-mcp/.venv/bin/sarvam-mcp --help || true It should print the help banner without crashing. 3. DETECT MCP CLIENTS Check which of these are installed on this machine and edit each one's MCP config to add a `sarvam` server. Use the ABSOLUTE binary path: ~/sarvam-mcp/.venv/bin/sarvam-mcp Client paths: • Cursor ~/.cursor/mcp.json • Claude Desktop ~/Library/Application Support/Claude/claude_desktop_config.json (macOS) ~/.config/Claude/claude_desktop_config.json (Linux) %APPDATA%\Claude\claude_desktop_config.json (Windows) • Claude Code run: claude mcp add sarvam -- ~/sarvam-mcp/.venv/bin/sarvam-mcp • Windsurf ~/.codeium/windsurf/mcp_config.json • Zed ~/.config/zed/settings.json (key: `context_servers`) For each JSON file, MERGE — don't clobber other servers. The new entry is: { "mcpServers": { "sarvam": { "command": "/.venv/bin/sarvam-mcp" } } } 4. (OPTIONAL) API KEY If I gave you a Sarvam API key, write it to ~/.sarvam/credentials: mkdir -p ~/.sarvam && chmod 700 ~/.sarvam printf "api_key = %s\n" "$KEY" > ~/.sarvam/credentials chmod 600 ~/.sarvam/credentials If I didn't, skip — Cursor / Claude Desktop will pop up an elicitation dialog asking for the key on the first tool call. 5. VERIFY Spawn the server and run an MCP tools/list to confirm 16 tools register: sarvam_stt_transcribe, sarvam_stt_translate, sarvam_stt_batch_submit, sarvam_stt_batch_status, sarvam_tts_speak, sarvam_tts_stream, sarvam_translate, sarvam_transliterate, sarvam_identify_language, sarvam_text_analytics, sarvam_llm_complete, sarvam_vision_extract, sv_voice, sv_dub, sv_localize, sv_recall Quick recipe (uses the script in the repo): SARVAM_API_KEY=<optional> ~/sarvam-mcp/scripts/probe_mcp.sh \ ~/sarvam-mcp/.venv/bin/sarvam-mcp 6. REPORT Tell me: • Where the repo is cloned • Which clients you detected and updated • Whether the API key was written • Any errors with the exact command + fix you'd recommend • A reminder to restart the MCP clients to pick up the new server If any step fails, stop and show me the error before continuing. Don't pretend a step succeeded if it didn't.
