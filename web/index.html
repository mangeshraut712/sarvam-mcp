FAQ

How does authentication work?

The server starts without a key. The first tool call prompts you in your editor (via MCP elicitation) to paste your Sarvam API key. The key is saved to ~/.sarvam/credentials with mode 0600 and never asked again. Get one at dashboard.sarvam.ai.

What if my MCP client doesn't support elicitation?

Three other ways to provide the key: run sarvam-mcp init in a terminal, set SARVAM_API_KEY in the client's env block, or hand-write ~/.sarvam/credentials.

Where do generated audio files go?

By default, ~/Desktop/. Override with SARVAM_MCP_BASE_PATH. To get audio inline as a base64 MCP resource (no disk writes), set SARVAM_AUDIO_OUTPUT_MODE=resources.

Is my data sent to Sarvam servers?

Tool calls go from your editor → local MCP server → api.sarvam.ai. The local server is a thin client; nothing extra is logged. Same data flow as using the Sarvam API directly.
